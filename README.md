# Python Data Storage & CRUD Projects

This repository contains Python assignments and a mini project focused on file handling, data storage, and CRUD operations.

## Projects

### 1. Contact Book

A contact management program using a Python dictionary.

**Features:**

* Add contact
* Search contact
* Update contact
* Delete contact

### 2. Word Counter

A Python program that reads a text file and counts:

* Words
* Lines
* Characters

### 3. JSON File Reader

A Python program that:

* Loads JSON data
* Reads JSON data
* Prints formatted output

### 4. Student Management System

A mini project for managing student records using a CSV file.

**Student Data:**

* Name
* Roll Number
* Marks

**Features:**

* Add student
* Search student
* Delete student
* Save changes permanently to the CSV file

## Skills Gained

* Python File Handling
* CSV File Handling
* JSON File Handling
* Dictionary
* CRUD Operations
* Data Storage
* Persistent Data Management

## Technologies Used

* Python
* CSV
* JSON
* File I/O
